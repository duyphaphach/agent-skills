# Angle catalog

The "angle" is the framing of an article - the same keyword can be written eight different ways. The researcher assigns one angle per outline; the auditor checks the outline holds that angle consistently.

| Angle | Framing | Best when |
|-------|---------|-----------|
| How-to / tutorial | Step-by-step path to a result | The reader wants to *do* something |
| Listicle | A ranked or grouped set of items | The topic is a set of options or tips |
| Comparison / vs | Two or more options weighed side by side | The reader is choosing between things |
| Beginner guide | Assumes no prior knowledge, defines terms | The keyword attracts newcomers |
| Expert deep-dive | Assumes background, goes past the basics | The audience is already informed |
| Case study | One real example examined in detail | A concrete story proves the point |
| Opinion / contrarian | A clear stance against the common view | The common advice is worth challenging |
| Problem-solution | Names a pain, then resolves it | The keyword is a complaint or a symptom |

## Picking an angle

- If the user named an angle in the inputs, every outline should serve it, but feel free to vary depth and audience.
- If the angle is "open", spread the 5 outlines across different angles so the marketer sees real choices.
- The dominant search intent decides what fits. A keyword people search to *learn* rarely suits an opinion piece.
