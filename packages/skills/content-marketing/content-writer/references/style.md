# Style - voice presets

The wording rules (in `content-auditor/references/wording-language-rules/`) cover structure, honesty, and locale. This file covers **voice** - the personality of the writing. Pick one per article.

| Preset | Sounds like | Use for |
|--------|-------------|---------|
| Helpful expert | Calm, plain, confident. Explains without talking down. | Default. Guides, how-tos, most content. |
| Friendly peer | Warm, casual, second person, light humor. | Lifestyle, beginner, community topics. |
| Authoritative | Formal, precise, source-heavy, no slang. | Finance, legal, health, regulated topics. |
| Punchy marketer | Short sentences, strong verbs, energetic. | Product launches, landing-page-style posts. |

## Picking a voice

- If the user named a voice, use it.
- If the topic is regulated (finance, legal, health), default to **Authoritative** even if no voice was named - it carries the care those topics need.
- Otherwise default to **Helpful expert**.

## Holding a voice

- Set the voice in the first paragraph and hold it to the last.
- The voice changes word choice and rhythm, never the facts or the structure.
- A voice is not an excuse to break a wording rule. Rules win.

`content-auditor` scores "voice and tone match" - a draft that drifts between voices loses those points.
